# scoopnote

Scoop digests and note fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/scoopnote/

## Install / run

```bash
git clone https://github.com/theworker02/scoopnote.git
cd scoopnote
node src/cli.js
node --test
```
